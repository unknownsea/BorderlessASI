# BorderlessASI

A simple ASI plugin that makes games run in a borderless window.

## Installation

1. Install [Ultimate ASI Loader](https://github.com/ThirteenAG/Ultimate-ASI-Loader).
2. Create a folder named `plugins` next to the game's executable.
3. Place `BorderlessASI.asi` inside the `plugins` folder.
4. Launch the game.
